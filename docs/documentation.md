# ***Калькулятор аннуитентного и дифференцированного платежа***
Проект в котором содержатся 2 программы для высчитывания платежа
в каждый месяц


## ***Общее описание решения***
*В проекте 2 консольные программы, которые считают
платеж при аннуитентном и дифференцированном кредите.*
1) В файле `DifferentiatedPayments.cpp`
   находится функция
   вычисления дифферинцированного платежа от суммы кредита, процента и срока, на который берется кредит.
- **Дифференцированный кредит** - кредит в котором сумма в каждый месяц на одну и ту же сумму меньше суммы на конец
2) В файле `AnnuityPayment.cpp` находится функция вычисления
   аннуитентного платежа от суммы кредита, процента и срока, на который берется кредит.
- **Аннуитетный кредит** - кредит, в котором каждый месяц выплата одинаковая.

### **Входные данные**
Две программы принимают одинаковые наборы данных:

| Данные           | Описание                           | Пример                 |
|------------------|------------------------------------|------------------------|
| Ставка (procent) | Процентная ставка по кредиту в год | `20` (20 процентов)    |
| Сумма кредита (amount) | Сумма, которая берется в кредит.   | `100000` (100000 рублей) |
| Срок кредита (year) | Срок, на который берется кредит в годах | `2` (2 года)            |

### **Структура проекта**

| Файл | Назначение                                                               |
|------|--------------------------------------------------------------------------|
| `AnnuityPayment.cpp` | расчёт аннуитетного платежа                                              |
| `DifferentiatedPayments.cpp` | вывод в консоль дифференцированных платежей в каждый месяц               |
| `CMakeLists.txt` | настройки сборки |
| `README.md` | краткое описание репозитория                                             |

### **Запуск**
1) Открыть проект в VS Code или Clion
2) Открыть файл AnnuityPayment.cpp для расчета аннуитентного платежа или DifferentiatedPayments.cpp для расчета дифиринцированного платежа.
3) Запустить и ввести данные.

## ***Описание функций***
### ***AnnuityPayment.cpp***
```cpp
double AnnuityPayment(int procent, int amount, int year); 
```
Принимает на вход 3 аргумента: `int procent`, `int amount`, `int year`:

| Аргумент | Значение |
 |----------|-----------------|
| procent | процентная ставка в год |
| amount | сумма, взятая в кредит в рублях |
| year | срок, на который взяли кредит (в годах) |

Возвращает значение `double` - ежемесячный платеж.

**Внутри функции реализуется формула подсчета ежемесячного платежа:**
```cpp
const double monthly_rate = (procent / 12.0) / 100.0;
const int month = year * 12;
const double l = std::pow(1 + monthly_rate, month); // l это коэффициент наращения
return amount * monthly_rate * l / (l - 1);
```
1) Сначала вычисляется процентная ставка (monthly_rate)
2) Количество лет переводится в месяцы (month)
3) Считается коэффициент наращения (l)
4) Считается и возвращается итоговый платеж

**Пример реализации функции**
``` cpp
double AnnuityPayment(20,10000,1);
```
Вывод:
```text
Ваш примерный ежемесячный платеж по кредиту составит: 926.345 рублей
```

### ***DifferentiatedPayments.cpp***
```cpp
void DifferentiatedPayment(double procent, double amount, int year); 
```
Принимает на вход 3 аргумента: `double procent`, `double amount`, `int year`:

| Аргумент | Значение |
 |----------|-----------------|
| procent | процентная ставка в год |
| amount | сумма, взятая в кредит в рублях |
| year | срок, на который взяли кредит (в годах) |

Возвращаемое значение: Функция ничего не возвращает. Выводит в консоль i-й месяц и платеж в этот месяц.

**Внутри функции реализуется формула подсчета ежемесячного платежа:**
```cpp
double monthly_rate = (procent / 12.0) / 100.0;
int mounth = year * 12;
double OstatDolg = amount;
double plan = amount / mounth;
for (int i = 1; i <= mounth; i++) {
    double payment = plan + OstatDolg * monthly_rate;
    std::cout << "В " << i << "-й месяц платеж составит: " << payment << "\n";
    OstatDolg = OstatDolg - plan;
```
1) Сначала вычисляется процентная ставка (monthly_rate)
2) Количество лет переводится в месяцы (month)
3) Вводится переменная остатка долга.
4) Вычисляется платеж без учета процентов. `plan = amount / mounth;`
5) Проходимся по всем месяцам и вычисляем платеж в каждый месяц
6) Выводим i-й месяц и платеж в консоль.

**Пример реализации функции**
``` cpp
void DifferentiatedPayment(10,200,1);
```
Вывод:
```text
В 1-й месяц платеж составит: 18.3333
В 2-й месяц платеж составит: 18.1944
В 3-й месяц платеж составит: 18.0556
...
В 12-й месяц платеж составит: 16.8056
````
