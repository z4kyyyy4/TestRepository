# ***Калькулятор аннуитетного и дифференцированного платежа***
Проект в котором содержатся 2 программы для высчитывания платежа в каждый месяц

- `AnnuityPayment` - считает аннуитетный платеж.
- `DifferentiatedPayments` - выводит график дифференцированных платежей по месяцам
## **Запуск программы**
1) Открыть проект в Vs Code или Clion
2) Выбрать AnnuityPayment.cpp или DifferentiatedPayments.cpp
3) Запустить и ввести данные: процент, сумму и срок кредита
