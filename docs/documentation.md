# ***Калькулятор аннуитентного и дифференцированного платежа***
Проект в котором содержатся 2 программы для высчитывания платежа
в каждый месяц


## ***Общее описание решения***
*В проекте 2 консольные программы, которые считают 
платеж при аннуитентном и дифференцированном кредите.*
1) В файле `DifferentiatedPayments.cpp`
находится функция
вычисления дифферинцированного платежа от суммы кредита, процента и срока, на который берется кредит.
- **Дифференцированный кредит** - кредит в котором сумма в каждый месяц на одну и ту же сумму меньше суммы на конец
2) В файле `AnnuityPayment.cpp` находится функция вычисления 
аннуитентного платежа от суммы кредита, процента и срока, на который берется кредит.
- **Аннуитетный кредит** - кредит, в котором каждый месяц выплата одинаковая.

### **Входные данные**
Две программы принимают одинаковые наборы данных:

| Данные           | Описание                           | Пример                 |
|------------------|------------------------------------|------------------------|
| Ставка (procent) | Процентная ставка по кредиту в год | `20` (20 процентов)    |
| Сумма кредита (amount) | Сумма, которая берется в кредит.   | `100000` (100000 рублей) |
| Срок кредита (year) | Срок, на который берется кредит в годах | `2` (2 года)            |

### **Структура проекта**

| Файл | Назначение                                                               |
|------|--------------------------------------------------------------------------|
| `AnnuityPayment.cpp` | расчёт аннуитетного платежа                                              |
| `DifferentiatedPayments.cpp` | вывод в консоль дифференцированных платежей в каждый месяц               |
| `CMakeLists.txt` | настройки сборки |
| `README.md` | краткое описание репозитория                                             |
| `docs/documentation.md` | документация проекта                                                     |

### **Запуск**
1) Открыть проект в VS Code или Clion
2) Открыть файл AnnuityPayment.cpp для расчета аннуитентного платежа или DifferentiatedPayments.cpp для расчета дифиринцированного платежа.
3) Запустить и ввести данные.
